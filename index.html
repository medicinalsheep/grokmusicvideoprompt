GrokMusicVideoPrompt

Structured music-video workflow for Grok Imagine Image 2.0 + Video 1.5. Intake → BPM → world lock → outline → title card → image-to-video → extend → assemble.

Who this is for

You already have a finished song as an .mp3 or .wav file, and you want a music video with Grok Imagine (Image 2.0 stills + Video 1.5 clips). Scope is yours — a few looped clips or a longer cut. This page builds the master prompt that locks planning, multi-ref consistency, and chain continuity.

How to use & tips (tap to expand)
Current Imagine stack
  • Image 2.0 — multi-ref stills, precision edits, character/location/prop “world” lock, sharper title text
  • Video 1.5 — up to ~15s clips, multi-ref (often up to 7), voice ref, native 1080p, text-to-video + image-to-video, improved Extend / Extend-from-frame
  • Preferred path — Image 2.0 world lock → image-to-video → same-scene Extend. Text-to-video is fine for B-roll, weaker for locked characters
Option A — Guided in Grok Copy a ready-made opener (link + short instructions) into a Grok chat, then attach your track. Best results: also fill the form and paste the Generated Master Prompt so Grok has the full rules, not only a URL.
Live tool medicinalsheep.github.io/grokmusicvideoprompt
Option B — Build the prompt yourself Fill out the form below, click Generate Master Prompt, copy it into a Grok chat, and attach your track. Flow: intake → BPM → Image 2.0 world lock → outline → title card → Scene 1 still → image-to-video → Extend → chain handoff → assemble.
What you’ll need
  • Finished track (.mp3 / .wav) — attach in Grok for BPM/structure
  • Song name, artist, rough mood
  • Optional: up to ~7 multi-image refs (character / location / props), voice ref, lyric notes
  • Grok app or grok.com (Image 2.0 + Video 1.5)
Clip length & continuity Plan in 6s / 10s / 15s bases (default 10s). Extensions stay in the same scene (motion only). For the next chain:
  • Prefer Extend / Extend from frame when the UI offers it, or
  • Screenshot the last frame and use it as the next start image — still the reliable continuity method
Don’t invent the next start from text alone if you want characters/scene to match.
Tips & edge cases
  • World lock first — use Image 2.0 multi-ref stills for character sheets, locations, and props before heavy video spend
  • 1080p — native on Video 1.5 when available; higher quality, higher usage
  • Native audio — keep your song as the bed, or allow Imagine complementary SFX/music if you choose
  • Grok app / grok.com for combine — not Grok-in-X
  • Scope — full cut or a few loops; free tiers and weekly usage still limit long form
  • Example — Report Card sample is style reference from an earlier model era; process still applies
