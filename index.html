GrokMusicVideoPrompt

Turn a finished track into a consistent Grok Imagine music video. Intake → outline → title card → Scene 1 image → base clip → extensions → next scene.

Who this is for

You already have a finished song as an .mp3 or .wav file, and you want to make a music video with Grok Imagine — planned scenes, matching style, and clips Grok can generate and combine into one consistent music video. This tool builds the structured prompt that keeps that workflow consistent.

How to use

Option A — Guided in Grok (easiest) Copy a ready-made opener (link + message) into a Grok chat. Grok can follow this tool’s workflow and walk you through generation step by step.
Live tool medicinalsheep.github.io/grokmusicvideoprompt
Option B — Build the prompt yourself Fill out the form below (including optional starting assets if you have them), click Generate Master Prompt, copy the result, and paste it into a Grok chat. Grok will confirm intake, then walk one step at a time: outline → title card → Scene 1 start image only → base video prompt → extension prompts → next scene.
What you’ll need
  • Your finished track (.mp3 or .wav) — the song the music video is built for
  • Song name, artist, and a rough visual mood
  • Optional but helpful: reference stills, character art, logos, lyric notes, or “must include” moments
  • Grok Imagine for stills, clips, extensions, and combining the video sequence
Clip length & workflow Pick a base length (6s / 10s / 15s; default 10s) and a workflow style:
  • Guided — one image/prompt at a time (recommended)
  • Full prompt pack — all copy-ready prompts after outline approval
Plan scenes in 1× / 2× / 3× your base length (helpers and placeholders update when you change clip length). Extensions stay in the same scene. At scene boundaries, grab the last frame as the next scene’s starting image.
Tips & edge cases
  • Use Grok tab or Grok app — when combining / mixing the final video, work in the Grok product (grok.com tab or the Grok app), not Grok inside the X tab.
  • 10s default — best balance; two extensions ≈ a clean 30s scene.
  • 15s — fewer chains for longer takes; full chain is 45s (heavier per clip).
  • 6s — snappier cuts / more scene changes; full chain is 18s.
  • Scene continuity — last frame of chain A → start image for chain B so Grok can combine clips cleanly.
  • Try the form — use Load example for the Report Card sample (based on a finished Grok music video), then Generate.
