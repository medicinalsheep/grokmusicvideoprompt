GrokMusicVideoPrompt

Turn a finished track into a consistent Grok Imagine music video. Intake → outline → title card → Scene 1 image → base clip → extensions → next scene.

Who this is for

You already have a finished song as an .mp3 or .wav file, and you want to make a music video with Grok Imagine — planned scenes, matching style, and clips you can extend, loop, or combine in Grok. Scope is up to you — a few looped clips or a longer cut. This tool builds the structured prompt that keeps the workflow consistent.

How to use & tips (tap to expand)
Option A — Guided in Grok Copy a ready-made opener (link + short instructions) into a Grok chat, then attach your track. Best results: also fill the form and paste the Generated Master Prompt so Grok has the full rules, not only a URL.
Live tool medicinalsheep.github.io/grokmusicvideoprompt
Option B — Build the prompt yourself Fill out the form below, click Generate Master Prompt, copy it into a Grok chat, and attach your track. Flow: intake → BPM pass → outline → title card → Scene 1 image → base clip → extensions → last-frame handoffs → assemble.
What you’ll need
  • Your finished track (.mp3 or .wav) — attach it in Grok for BPM/structure
  • Song name, artist, and a rough visual mood
  • Optional: multi-image refs, voice ref, lyric notes, must-include moments
  • Grok (app or grok.com) with Imagine for stills, video, and combining clips
Clip length & workflow Pick a base length (6s / 10s / 15s; default 10s) and a workflow style:
  • Guided — one image/prompt at a time (recommended)
  • Full prompt pack — all copy-ready prompts after outline approval
Plan scenes in 1× / 2× / 3× your base length (helpers and placeholders update when you change clip length). Extensions stay in the same scene. For continuity between chains: screenshot the last frame of the finished clip (e.g. after a full 30s = base + 2 ext) and use that still as the starting image for the next clip — don’t invent the next start from text alone.
Tips & edge cases
  • Scope is yours — full production cut, a few looped clips, or whatever fits your tokens and taste. You don’t need a long-form MV.
  • Use Grok tab or Grok app — when combining / mixing, work in the Grok product (grok.com tab or the Grok app), not Grok inside the X tab.
  • Two consistency layers — (1) re-attach multi-image character/location refs in Imagine when you can; (2) screenshot the last frame of a finished chain for the next start. Refs help identity; last-frame keeps shot flow. Text-only next starts break consistency.
  • Voice ref (optional) — for character speech if Imagine offers it; your song file is still the music bed.
  • BPM in Grok — attach your track in chat; Grok should estimate BPM / structure and plan scene times (this page does not read the file; correct Grok if the estimate is off).
  • 10s default — best balance; two extensions ≈ a clean 30s scene. 15s fewer gens; 6s montage/loops.
  • Try the form — use Load example for the Report Card sample, then Generate.
