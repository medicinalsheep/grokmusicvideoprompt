# GrokMusicVideoPrompt

Structured prompt architect for consistent Grok music videos.

Forces a black title card → scene plan → image → 10s video → always extend from last frame.

## Live site

**https://medicinalsheep.github.io/grokmusicvideoprompt/**

## Usage

1. Fill in song details, visual direction, and scene timeline
2. Click **Generate Master Prompt**
3. Copy the prompt into Grok and follow the workflow

## Local

Open `index.html` in a browser — no build step required.
